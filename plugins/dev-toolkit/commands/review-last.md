## Контекст

- Текущий git статус: !`git status`
- Текущий git diff последнего коммита: !`git diff HEAD~1`
- Текущая ветка: !`git branch --show-current`

## Твоя задача

Проведи code review последнего коммита (`git diff HEAD~1`).

Определи стек проекта по файлам в корне:
- **PHP** (`composer.json`)
- **Go** (`go.mod`)
- **JS/TS** (`package.json`)
- другой стек

По изменениям из блока «Контекст» проверь:
1. Соответствие архитектурным соглашениям из CLAUDE.md.
2. Типизация, обработка ошибок, edge cases, отсутствие хардкода секретов.
3. Проблемы производительности: N+1 запросы, лишние аллокации, неоптимальные циклы.
4. Корректность doc-комментариев по стеку проекта (PHPDoc / GoDoc / JSDoc / docstrings).
5. Покрытие тестами (есть ли тесты для новой логики?).

При необходимости читай затронутый и соседний код (`Read`, `Grep`, `Glob`), чтобы оценить изменения в контексте.

Выведи список замечаний с приоритетами и указанием файла/строки.
